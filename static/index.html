🛡️ 上下文保护（防任务中断）

        

          开启后，当对话/任务即将超出模型上下文窗口时，网关会自动省略最早的历史内容并继续推理，避免报错中断。
仅在即将超窗时触发；系统指令与最近对话始终保留。
          
        

      

      

        
🧠 思考控制（统一策略）

        

          

        

          

        

          允许用户自定义思考

          开启后，使用者可通过 API Key 设置或客户端参数（如 /effort）自行调整思考开关与强度；关闭则一律使用上面的统一策略。
          
        

        

          

        

          · 开启思考时，网关照此额度抬高上游 max_tokens，确保思维链不会把输出额度吃光。

          · 若不抬高，客户端若只申请 8192，思维链或长回答就会占满额度、内容被截断，前端报 MAX_TOKENS 并中断任务。

          · 建议 8192（实测 Bonsai2 单轮自然输出约 12.8k）；模型已设「思考预算」时该保护是双保险，可保持不变。

          · 上限还受网关常量 _MAX_OUT（当前 16384）约束，客户端申请超过 8192 时预留空间会被压缩。

📖 使用说明

        

          1. 在「模型管理」新增/编辑模型，配置模型文件与参数；

          2. 点击「启动」运行模型，日志可在弹窗查看；

          3. 在「API 密钥与用量」创建 Key，分配给使用者；

          4. 使用者通过统一网关调用（OpenAI 兼容接口）；

          5. 用量统计自动记录每个 Key 的 Token 消耗。
